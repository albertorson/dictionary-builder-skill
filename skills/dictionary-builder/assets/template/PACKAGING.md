# 打包与使用

1. 运行 `python build.py`，在 local_output 找到 Simple 和 Extended 两个 TXT。
2. 在 Windows 从[欧路官方页面](https://www.eudic.net/v4/en/home/EudicBuilder)获取 EuDicBuilder。选择一个 TXT 作为自定义文本输入，填写词库名称；当前内容不需要外部资源目录。
3. 执行生成/压缩，保存为 .eudic。对另一版重复操作，使用不同的名称和输出文件。
4. 在欧路的词库管理中添加成品并启用，查一个已有词和一个新增词；增强版还需检查折叠、中文和例句。

工具按钮名称以安装版本为准。TXT 不能通过改后缀成为 .eudic。更详细的导入步骤参见[安装教程](https://github.com/albertorson/CS-AI-Dictionary/blob/main/docs/INSTALL.md)。
